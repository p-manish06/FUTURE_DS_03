# FUTURE_DS_03
# E-Commerce Funnel & Conversion Performance Analysis

## Overview
This project analyzes user behavior in an e-commerce platform to understand how users move through the conversion funnel: View → Cart → Purchase. The goal is to identify drop-off points, measure conversion rates, and provide actionable insights to improve business performance.

## Objective
- Analyze user journey across funnel stages  
- Measure conversion rates at each stage  
- Identify major drop-off points  
- Evaluate performance across categories and brands  
- Provide data-driven recommendations  

## Dataset
E-Commerce User Behavior Dataset (Kaggle):  
https://www.kaggle.com/datasets/mkechinov/ecommerce-behavior-data-from-multi-category-store

The dataset contains millions of records capturing user interactions such as product views, cart additions, and purchases along with product and time-related information.

## Tools Used
- Power BI  
- Power Query  

## Key Metrics
- Total Views  
- Total Cart  
- Total Purchase  
- View to Cart Conversion Rate  
- Cart to Purchase Conversion Rate  
- Overall Conversion Rate  

## Funnel Structure
- View: User views a product  
- Cart: User adds product to cart  
- Purchase: User completes purchase  

## Key Insights
- Major drop-off occurs at the View to Cart stage  
- Cart to Purchase conversion is relatively strong  
- Overall conversion rate is low, indicating improvement opportunities  
- A few categories contribute to most purchases  
- Top brands dominate overall sales  

## Recommendations
- Improve product pages with better visuals and descriptions  
- Reduce cart abandonment using offers and retargeting strategies  
- Focus marketing on high-performing categories and brands  
- Optimize pricing strategies based on user behavior  
- Enhance user experience to increase engagement  

## Project Outputs
- Interactive Power BI dashboard  
- Funnel analysis visualization  
- Conversion metrics and insights  
- Business recommendations
